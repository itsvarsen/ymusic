# ⅄music

A warm, dark, glassy Android music player for the music you own. Built with Flutter.

- Only plays files you pick (system file picker, or a folder you choose). Never scans the device.
- Files are copied into the app's private storage and deduplicated by content hash.
- Tags and embedded covers are read with `audio_metadata_reader`; missing covers get a warm gradient.
- Background playback, media notification and lock-screen controls via `just_audio` + `just_audio_background`.

## Build

CI (`.github/workflows/build.yml`) runs `flutter create --platforms=android` to generate the
Android project, applies `android_overrides/` and signing via `tool/patch_android.py`, then
runs `flutter build apk --release`. The APK is uploaded as the `ymusic-apk` artifact.

Local build (needs Flutter + Android SDK):

```bash
flutter create --platforms=android --org tech.varsen --project-name ymusic .
flutter pub get
dart run flutter_launcher_icons
python3 tool/patch_android.py
flutter build apk --release
```

Icons are generated by `tool/make_icon.py` (Pillow).
